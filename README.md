# Gymbro Daily

เว็บไซต์ติดตามการออกกำลังกาย/โภชนาการ/การนอน ภาษาไทย — แบบสอบถาม onboarding 9 หมวด →
สร้างตารางฝึก + เป้าหมายรายวันให้อัตโนมัติ → เช็คลิสต์ใช้งานประจำวัน

พอร์ตมาจากต้นแบบ Claude Artifact เดิม ตัดการพึ่งพาระบบ Artifact ออกทั้งหมดแล้ว
เป็นเว็บไซต์ **static site** ธรรมดา (HTML/CSS/JS, ไม่มี build step, ไม่มี backend)

## โครงสร้างไฟล์
- `index.html` — โครง HTML เปล่า (โหลด style.css + app.js)
- `style.css` — สไตล์ **พื้นฐาน** ตั้งใจให้เรียบง่าย รอนำไปออกแบบใหม่ทีหลัง
  (ชื่อ class ใน HTML ที่ generate จาก JS คงที่ ออกแบบใหม่ทับ CSS นี้ได้โดยไม่ต้องแก้ JS)
- `app.js` — ตรรกะทั้งหมด: คำถามแบบสอบถาม, generator เลือกท่า/ตารางฝึก, คำนวณโภชนาการ,
  หน้าใช้งานประจำวัน (วันนี้/ตารางฝึก/ความคืบหน้า/แผนของฉัน)
- `.claude/serve.js` + `.claude/launch.json` — สคริปต์รันเซิร์ฟเวอร์ static ไฟล์เดียว (ไม่มี dependency)
  ไว้ใช้ตอนพัฒนา/ทดสอบเท่านั้น ไม่จำเป็นสำหรับ deploy จริง

## การเก็บข้อมูล
ข้อมูลทั้งหมดเก็บใน **localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น** (ยังไม่มี backend/บัญชีผู้ใช้):
- `gymbro_program` — แผนที่ล็อกไว้ตอนกด "เริ่มโปรแกรม"
- `gymbro_logs` — บันทึกรายวันทั้งหมด
- `gymbro_weights` — น้ำหนักตัวที่ชั่งแต่ละวัน
- `gymbro_onb_proto` — ความคืบหน้าของแบบสอบถามระหว่างตอบ (resume ได้)

ล้างแคช/เปลี่ยนเครื่อง/เปิดโหมดไม่ระบุตัวตน = ข้อมูลหาย ยังไม่มีระบบซิงก์ข้ามอุปกรณ์

## วิธีรันดูเว็บ
เปิด `index.html` ตรงๆ ในเบราว์เซอร์ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์) หรือถ้าอยากรันผ่านเซิร์ฟเวอร์:

```bash
node .claude/serve.js
```

แล้วเปิด http://localhost:8934

## สถานะปัจจุบัน
UI/UX เป็นเวอร์ชันพื้นฐาน (ยังไม่ผ่านการออกแบบจริง) — ตรรกะ/ตัวเลข generator (sets/reps/tier,
เกณฑ์แคลอรี่ ฯลฯ) ยังเป็น placeholder ที่ยังไม่ผ่านการ review จากเทรนเนอร์/นักโภชนาการตัวจริง
