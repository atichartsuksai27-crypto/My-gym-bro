# ฐานความรู้สำหรับ Coach Agent

ไฟล์ .md ในโฟลเดอร์นี้คือฐานความรู้ที่ Coach Agent (ยังไม่ได้สร้าง — ดู Phase 2 เป็นต้นไป)
จะโหลดเข้า system prompt ตอนเรียก Claude API เพื่อตอบคำถามผู้ใช้แอป

## ต้นทางอยู่ที่ Obsidian ไม่ใช่ที่นี่

ไฟล์เหล่านี้เป็น **สำเนา export** จาก `D:\Obsidian\coach-knowledge\` (เครื่องเดียวกับที่
พัฒนาแอปนี้) — **ห้ามแก้ไฟล์ในโฟลเดอร์นี้โดยตรง** เพราะจะไม่ถูกนำกลับไปที่ต้นทาง แก้ที่
วอลต์ Obsidian ก่อนเสมอ แล้วค่อย copy ไฟล์มาทับที่นี่ + commit ใหม่อีกครั้ง (ไม่มีระบบ
sync อัตโนมัติระหว่างสองที่นี้)

## ไฟล์

- `principles.md` — สูตร/หลักการที่แอปคำนวณจริง (BMR, TDEE, มาโคร, การเลือกท่า/split,
  strength benchmark, ขอบเขตที่รองรับ)
- `faq.md` — คำถามผู้ใช้ที่พบบ่อย พร้อมคำตอบมาตรฐาน
- `safety-boundaries.md` — เส้นแบ่งที่ agent ห้ามข้าม (**สำคัญที่สุด** ต้องอยู่ใน
  system prompt เสมอ)
